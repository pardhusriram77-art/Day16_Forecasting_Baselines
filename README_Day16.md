# Day 16 — Forecasting Baselines

## Contents
- `Day16_Forecasting_Baselines.ipynb` — runnable notebook
- `day16_outputs/forecast_metrics.csv` — MAE/RMSE results
- `day16_outputs/forecast_predictions.csv` — holdout predictions
- `day16_outputs/chronological_split.csv` — split boundaries
- `day16_outputs/actual_vs_predicted.png` — time-series plot
- `day16_outputs/predicted_vs_actual_scatter.png` — scatter comparisons
- `water_potability_temporal_synthetic.csv` — input dataset

## Models
Persistence baseline, Linear Regression, and Random Forest regression.

## Data limitation
The source water-potability dataset is static. The timestamps are synthetic and are used only to demonstrate temporal preprocessing and forecasting workflow. Metrics are exploratory and are not evidence of real-world underwater sensor forecasting performance.

## Run
Open the notebook in Google Colab or Jupyter. Keep the CSV beside the notebook, or upload it when prompted. Run all cells from top to bottom.
